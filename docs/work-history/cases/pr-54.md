## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
Adds a map-location registration entry point for monitoring arbitrary coordinates, including offshore and addressless locations. Keeps current-location and place search flows unchanged. Reverse geocoding is best-effort; raw coordinates remain registrable when no address exists. Marks these targets with location_source MAP. This is the first safe step toward a visual map/rain-overlay picker.
```
