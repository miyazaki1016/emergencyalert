```text
## Background
PR #62 ran real-JMA stride parity on 2026-10-16 (Actions run 38967793373): six fully available z4 frames showed 177 >=30mm/h pixels with full coverage versus 45 using stride 2; 47 of 88 independent 4-connected heavy-rain regions had no stride-2 detection. These values apply to that sample only, not a global missed-alert rate.

## Changes
- Explicit `stride=1` in BOTH nationwide z4 first-pass routes (`national-preview`, `national-queue`) for observation and forecast frames. Keep shared scan function default untouched until detailed worker throughput is tested.
- Preview returns 503 when any required z4 tile is unavailable or corrupt, rather than silently treating missing coverage as no rain.
- Regression tests assert explicit stride=1 and incomplete-tile failure.
- `docs/NATIONAL_Z4_STRIDE_EVIDENCE_20261109.md` captures PR #62 results, methods and next gates.

## Limits and release scope
Targets existing feature branch PR #59, **not main**. No Supabase data, MYアメふる push, cron, storage, production deploy, or merge. Tests committed; CI result still unconfirmed. This is not production readiness: z4-to-z10 sensitivity, detailed worker’s stride, partition IO and scheduler remain to be verified.
```

```text
+# 全国大雨：ズーム4全画素走査の根拠と共通化の境界
+
+更新日：2026-11-09。既存研究の再確認・開発ブランチでの安全修正。**本番は変更しない。**
+
+## 実証済みの先行検証（PR #62）
+
+[PR #62](https://github.com/miyazaki1016/emergencyalert/pull/62) の GitHub Actions 実行 [Z4 stride parity #12](https://github.com/miyazaki1016/emergencyalert/actions/runs/38967793373) は 2026-10-16 に成功。Run 内で公開JMA z4画像の観測3時刻・予報3時刻（それぞれ6タイル、完全取得）について、全画素（stride=1）と縦横1つおき（stride=2）を比較した。
+
+| 指標 | 全画素 z4 | stride=2 |
+| --- | ---: | ---: |
+| 30mm/h以上の画素（6時刻合計） | 177 | 45 |
+| 全画素から省かれた強雨画素 | - | 132 |
+| 4近傍連結で独立した強雨域 | 88 | **47域は検出画素がゼロ** |
+
+時刻別の見逃し域は観測で10, 7, 6、予報で8, 7, 9。これは**対象時刻・検証画像に限った事実**であり、全国すべての天候での一般化された見逃し率・地上実降雨の予報適中率を示さない。
+
+同じランで、全画素 z4 は画像スキャン部分が数十ms程度で、単純な走査間引きが大きな節約になるとは限らない。ただし全画素化は、ズーム10詳細候補、タイル取得、DB処理を増やし得る。**運用コストの合否は未決定**。
+
+## 実装判断（本変更）
+
+- 既存の `scanHeavyRainTile(..., stride=2)` の**デフォルトは変更しない**。他の呼び出し（詳細ワーカーなど）の処理負荷を評価せずに広範囲へ副作用を出さないため。
+- 全国版の **z4第一次走査**を行う `national-preview` と `national-queue` では、明示的に `stride=1` を指定。観測・予報とも同一条件で見る。
+- PR #181で、6枚の必須z4タイルの欠損・破損を「大雨なし」と偽らず 503 にする安全策も追加した。
+- MYアメふるの z10 地点別予報と共通にするのは**公式PNG色→雨量階級→30/50/80mm/h判定の意味**。全国での探索と個別地点の通知ロジックは分離したままとする。
+
+## 次の検証ゲート
+
+1. **全画素z4の対象検知率 vs z10**：z4で強雨がないのにz10だけ30mm/h以上の雨域があるか、既存の z4→z8/z10 検証と比較する。PR #62は**z4内のstride比較**であり、ズーム間の保証ではない。
+2. z4→z10の詳細候補数・対象タイル数・負荷を同一画像群で再測定。ズーム10ワーカーにも stride=2 のデフォルトが残るので、細い雨域の検知精度を検証する。初回検証前に本番へ広げない。
+3. 既存の 32MiB分割データローダー、所有者集約、キューの期限管理、スケジューラを安全に統合し、端から端までの性能・完全性を証明する。
+4. 本番MYアメふるの通知と既存データは無変更。スキャンと通知・公開表示は別リリース判定とする。
+
+再検証時は既存ソース `scripts/z4-stride-parity-proof.ts`、`scripts/z4-stride-performance-proof.ts` および実行ログを正本として使用し、同じ実験を発見し直さない。
```
