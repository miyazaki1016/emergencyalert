+# 元の目的を見失わない中断・復帰手順
+
+中断や引き継ぎが必要な案件を[開発台帳](DEVELOPMENT_LEDGER.md)に記録する。美咲とアメふるで同じ項目を使用する。アメふるの最初の登録案件は、通知文C案の [Issue #205](https://github.com/miyazaki1016/emergencyalert/issues/205) と、その[実装への引き継ぎ記録](https://github.com/miyazaki1016/emergencyalert/issues/204#issuecomment-6793492527)。
+
+## 担当ソラの手順
+
+1. 既存の着手前照合に合格したら、台帳の `work-resume:v1` チェックポイントを読む。日次棚卸しのSummary／`development-inventory` 成果物に `resume-candidates.md` とJSONもある。通常チャットは台帳だけでも目的と次の一手を読める。
+2. 別の不具合へ移る**前**に、元のIssueを `paused` として、`pause_reason`、中断位置（コード・テスト・SHA・資料へのリンク）、次の一手、復帰条件を記録する。不具合は別Issueで扱い、本文に親Issueをリンクする。親の `blocked_by` に子Issue番号を記録する。子Issueを作っただけで元案件を完成扱いしない。
+3. 子の修正が終わったら、本当に受入条件を満たしたかを証拠で確認してから子を完了にする。次の日次／手動棚卸しでは、全子Issueが `closed/completed` の親を「再開待ち」と表示する。未取得・削除・not_planned等は「要確認」。再開候補は着手許可でも親の完了でもない。複数の子があれば全件を確認する。
+4. 担当AIが元の制約・最新照合結果・復帰条件を確認し、親へ戻る。戻れない場合は理由と次の確認事項を残す。復帰後は親を active に更新し、実際に戻った担当・日時・再開地点・作業証拠を resumed に記録する。保留する場合は理由と review_when に再確認条件を残す。再度中断したら過去の復帰記録をGit履歴に残し、現在のチェックポイントの resumed を外す。
+5. 作業終了・チャット引き継ぎ時にも、未完了の親目的が残っていないか確認する。合格待ちや許可範囲のルールをこの手順で迂回しない。
+
+台帳が正本。Issue本文はリンクと文脈、履歴は過去の根拠、生成一覧は現在の再開候補を担う。新しい状態台帳を別ファイルに作らない。チェックポイントの変更履歴はGitで保持し、過去の判断・証拠は削除せず日付付きで追記する。Issue本文を更新した場合は従来どおり最新本文に対する再照合を待つ。
+
+## 正本の項目
+
+`issue` は親Issue番号、`goal` は完成させる目的、`status` は active／paused／review／complete、`updated` は確認日、`pause_reason` は中断理由、`blocked_by` は復帰を妨げている子Issue番号、`next` は中断位置と次の具体的一手、`completion` は完了条件、`evidence` は証拠リンク。子は同一リポジトリのIssueに限る。事実がない依存関係は作らない。手動保留は子なしでも記録できるが、自動的に再開候補へ変えない。
+
+`stages` は implementation（実装）／verification（最新変更の必要な検証）／main（統合）／production（本番反映と実経路）／device（実機）を別々に記録する。状態は unconfirmed／passed／not_applicable。passedや対象外の主張にも根拠を付ける。研究・管理案件の本番や実機は、完了条件に照らして対象外とする理由を記録する。全段階の根拠と受入条件を人が確認するまでcompleteにしない。URLがあるだけでコード内容・CI対象SHA・実デプロイ一致を自動認定しない。
+
+## 生成と確認
+
+~~~sh
+python3 -m unittest discover -s tests -p 'test_development_resume.py' -v
+python3 scripts/development_resume.py --live
+~~~
+
+生成処理は既存 `report.json` と台帳を読み、子Issueだけを既存の読取りAPIで確認する。`--live` なしは保存済みスナップショットだけで判定し、未取得の子を完了と推定しない。既存の日次Actionsに組み込み、短期トークンの既存read権限だけを使う。APIキー・外部AI・DB接続は不要。
+
+日次の再開候補表示は、Issue編集や親状態の自動更新をしない。子の終了直後に即時反映するイベント処理は未導入。Actionsの成果物は既存の30日保存、正本はGitに残る。自動書込みは読み取り試行の確認後に別途検討する。
+
+候補生成ステップは追加報告として分離し、失敗しても既存の履歴収集・公開を止めない。候補ファイルがない場合は「再開候補なし」ではなく「生成未確認」と扱い、正本の台帳を読む。
+
+## 担当ソラへ渡す記録
+
+日次棚卸しの `resume-candidates.md` で親Issueの引き継ぎ欄を確認する。次の一手・完了条件・子案件の状態・実際の再開記録・根拠リンクをまとめて参照できる。再開待ちは、台帳に復帰の作業証拠を記録するまで残る。再開日時はタイムゾーン付き、証拠は実際の作業が確認できるHTTPS URLとする。
+
+`resumed` は active の親に記録し、担当を `by`、日時を `at`、再開地点を `from`、作業記録URLを `evidence` に入れる。`review_when` には再確認する条件を書く。
+
+PRのCIを根拠に使うときは、`stages.verification` に `pr`（PR番号）と `head_sha`（検証対象の40桁SHA）を対で記録する。棚卸し時のPR HEADと異なる場合は「最新HEADのCIを再確認」、取得できない場合は「要確認」を表示する。SHAが一致した場合も、CIの結果・本番版・実機動作はそれぞれの原本で確認する。

+#!/usr/bin/env python3
+"""Read-only resume candidates from the canonical ledger; never change Issue state."""
+import argparse
+import json
+import re
+from datetime import datetime
+from pathlib import Path
+from development_history_evidence import clean
+
+MARKER = re.compile(r'<!-- work-resume:v1\s*(.*?)\s*-->', re.S)
+STAGES = ('implementation', 'verification', 'main', 'production', 'device')
+SHA = re.compile(r'[0-9a-f]{40}')
+
+
+def checkpoints(text):
+    blocks = MARKER.findall(text)
+    if len(blocks) != 1:
+        raise ValueError('Expected one work-resume:v1 block in canonical ledger')
+    rows = json.loads(blocks[0])['checkpoints']
+    if not isinstance(rows, list):
+        raise ValueError('Invalid checkpoints')
+    seen = set()
+    for row in rows:
+        number = row.get('issue')
+        if type(number) is not int or number < 1 or number in seen:
+            raise ValueError('Invalid or duplicate Issue')
+        seen.add(number)
+        if row.get('status') not in ('active', 'paused', 'review', 'complete'):
+            raise ValueError('Invalid status')
+        for key in ('goal', 'next', 'updated', 'completion'):
+            if not isinstance(row.get(key), str) or not row[key].strip():
+                raise ValueError('Missing checkpoint field: ' + key)
+        children = row.get('blocked_by', [])
+        if not isinstance(children, list) or any(type(n) is not int or n < 1 or n == number for n in children):
+            raise ValueError('Invalid blocking Issue')
+        if row['status'] == 'paused' and not row.get('pause_reason'):
+            raise ValueError('Paused checkpoint needs a reason')
+        if 'review_when' in row and not (isinstance(row['review_when'], str) and row['review_when'].strip()):
+            raise ValueError('Invalid review condition')
+        if 'resumed' in row:
+            receipt = row['resumed']
+            if (row['status'] != 'active' or not isinstance(receipt, dict)
+                    or any(not isinstance(receipt.get(k), str) or not receipt[k].strip()
+                           for k in ('by', 'at', 'from', 'evidence'))
+                    or not re.fullmatch(r'https://[^\s<>]+', receipt['evidence'])
+                    or datetime.fromisoformat(receipt['at'].replace('Z', '+00:00')).utcoffset() is None):
+                raise ValueError('Invalid resumption record')
+        for stage, value in row.get('stages', {}).items():
+            if stage not in STAGES or value.get('status') not in ('unconfirmed', 'passed', 'not_applicable'):
+                raise ValueError('Invalid stage')
+            if value['status'] != 'unconfirmed' and not value.get('evidence'):
+                raise ValueError('Stage assertion needs evidence')
+            if stage == 'verification' and ('pr' in value or 'head_sha' in value):
+                if (type(value.get('pr')) is not int or value['pr'] < 1
+                        or not isinstance(value.get('head_sha'), str) or not SHA.fullmatch(value['head_sha'])):
+                    raise ValueError('Invalid verification PR or SHA')
+        if row['status'] == 'complete' and any(row.get('stages', {}).get(s, {}).get('status') not in ('passed', 'not_applicable') for s in STAGES):
+            raise ValueError('Complete checkpoint has unconfirmed stages')
+    # Do not accept cycles between tracked checkpoints.
+    graph = {r['issue']: r.get('blocked_by', []) for r in rows}
+    def walk(n, path):
+        if n in path:
+            raise ValueError('Cyclic checkpoint dependency')
+        for child in graph.get(n, []):
+            walk(child, path | {n})
+    for n in graph:
+        walk(n, set())
+    return rows
+
+
+def build(rows, lookup, prs=None):
+    result = []
+    for row in rows:
+        children = []
+        for number in row.get('blocked_by', []):
+            try:
+                issue = lookup(number)
+                # Closing as not_planned is not evidence that a blocking fix finished.
+                done = (issue.get('number') == number and not issue.get('pull_request')
+                        and issue.get('state') == 'closed' and issue.get('state_reason') == 'completed')
+                state = 'completed' if done else 'open' if issue.get('state') == 'open' else 'unconfirmed'
+            except Exception:
+                state = 'unconfirmed'
+            children.append({'issue': number, 'state': state})
+        status = row['status']
+        candidate = ('要確認' if any(c['state'] == 'unconfirmed' for c in children)
+                     else '子案件対応中' if any(c['state'] == 'open' for c in children)
+                     else '再開待ち' if status == 'paused' and children
+                     else '保留・復帰条件を確認' if status == 'paused'
+                     else '完了記録（証拠を再確認）' if status == 'complete'
+                     else '再開記録あり' if row.get('resumed')
+                     else '継続候補')
+        entry = {**row, 'candidate': candidate, 'children': children, 'auto_applied': False}
+        verification = row.get('stages', {}).get('verification', {})
+        if 'pr' in verification:
+            current = (prs or {}).get(str(verification['pr']), {}).get('head')
+            recorded = verification['head_sha']
+            entry['verification_head'] = {
+                'pr': verification['pr'], 'recorded': recorded, 'current': current,
+                'status': 'unconfirmed' if not current else 'matched' if current == recorded else 'changed',
+            }
+        result.append(entry)
+    return result
+
+
+def render(rows, repository, generated_at):
+    safe = lambda x: clean(str(x)).replace('|', '&#124;').replace('\n', ' ')
+    lines = ['# 中断した目的と再開候補', '', '取得時刻：' + safe(generated_at), '',
+             '開発台帳のチェックポイントから生成。子Issueの完了は復帰条件の候補であり、親の完成・着手許可・本番反映ではない。', '',
+             '| 親案件・目的 | 状態 | 中断理由／子案件 | 次の一手 |', '| --- | --- | --- | --- |']
+    for row in rows:
+        url = f"https://github.com/{repository}/issues/{row['issue']}"
+        children = ', '.join(f"[#{c['issue']}](https://github.com/{repository}/issues/{c['issue']})：{c['state']}" for c in row['children'])
+        lines.append(f"| [#{row['issue']}]({url}) {safe(row['goal'])} | {safe(row['candidate'])} | {safe(row.get('pause_reason', ''))} {children} | {safe(row['next'])} |")
+    for row in rows:
+        issue_url = f"https://github.com/{repository}/issues/{row['issue']}"
+        lines += ['', f"## [#{row['issue']}]({issue_url}) の引き継ぎ", '',
+                  f"- 目的と状態　{safe(row['goal'])} ／ {row['candidate']}",
+                  f"- 次の一手　{safe(row['next'])}",
+                  f"- 完了条件　{safe(row['completion'])}"]
+        if row.get('pause_reason'):
+            lines.append(f"- 中断理由　{safe(row['pause_reason'])}")
+        if row.get('review_when'):
+            lines.append(f"- 再確認条件　{safe(row['review_when'])}")
+        for child in row['children']:
+            child_url = f"https://github.com/{repository}/issues/{child['issue']}"
+            state = {'completed': '完了', 'open': '対応中', 'unconfirmed': '要確認'}[child['state']]
+            lines.append(f"- 子案件　[#{child['issue']}]({child_url}) ／ {state}")
+        if receipt := row.get('resumed'):
+            lines.append(f"- 再開記録　{safe(receipt['by'])} ／ {safe(receipt['at'])} ／ {safe(receipt['from'])} [作業記録](<{safe(receipt['evidence'])}>)")
+        if check := row.get('verification_head'):
+            label = {'unconfirmed': '現在のSHAを取得できず要確認', 'matched': '対象SHA一致',
+                     'changed': 'PRが更新されたため最新HEADのCIを再確認'}[check['status']]
+            lines.append(f"- 検証　[PR #{check['pr']}](https://github.com/{repository}/pull/{check['pr']}) ／ {label} ／ 記録SHA `{safe(check['recorded'])}` ／ 現在SHA `{safe(check['current'] or '未取得')}`")
+        for stage, label in (('verification', '検証'), ('production', '本番'), ('device', '実機')):
+            stage_record = row.get('stages', {}).get(stage, {})
+            for evidence in stage_record.get('evidence', []):
+                lines.append(f"- {label}の台帳根拠　{safe(evidence)}")
+        for evidence in row.get('evidence', []):
+            lines.append(f"- 参照資料　{safe(evidence)}")
+    lines += ['', '状態の自動変更・コメント投稿・マージ・デプロイ・通知送信なし。再開前の既存成果照合と元の許可条件を守る。', '']
+    return '\n'.join(lines)
+
+
+def main():
+    parser = argparse.ArgumentParser()
+    parser.add_argument('--ledger', default='docs/DEVELOPMENT_LEDGER.md')
+    parser.add_argument('--report', default='inventory-output/report.json')
+    parser.add_argument('--output', default='inventory-output')
+    parser.add_argument('--live', action='store_true')
+    args = parser.parse_args()
+    report = json.loads(Path(args.report).read_text())
+    repository = report['repository']
+    if not re.fullmatch(r'[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+', repository):
+        raise ValueError('Invalid repository')
+    rows = checkpoints(Path(args.ledger).read_text())
+    if args.live:
+        # Reuse the existing read-only API transport; credentials never enter the report.
+        from development_inventory import get
+        lookup = lambda n: get(f'/repos/{repository}/issues/{n}')
+    else:
+        def lookup(n):
+            value = report['snapshot']['issues'][str(n)]
+            return {'number': n, **value}
+    result = build(rows, lookup, report.get('snapshot', {}).get('prs', {}))
+    output = Path(args.output)
+    output.mkdir(parents=True, exist_ok=True)
+    (output / 'resume-candidates.json').write_text(clean(json.dumps({'repository': repository, 'generated_at': report['generated_at'], 'candidates': result, 'auto_applied': False}, ensure_ascii=False, indent=2)) + '\n')
+    text = render(result, repository, report['generated_at'])
+    (output / 'resume-candidates.md').write_text(text)
+    print(text)
+
+
+if __name__ == '__main__':
+    main()

# 引継ぎ・再利用・変更検証・案件完成を分けて記録する共通ルール

美咲・アメふる共通。通常チャットの担当AIが使う。過去の照合成功・CI成功を、新しい変更や案件全体の完成へ読み替えない。

## 既存の仕組みを調べた結果

| 要件 | 既存対応 | 今回補う点 |
| --- | --- | --- |
| 既存PR・研究・証拠の発見と再利用判断 | `development_preflight.py` とIssue／PRの `history-preflight` が対応済み | 同じ照合器は作らない |

| 通常チャットで結果を読む | Issue本文から依頼を起動、ActionsのSummary・ログ・成果物に結果あり | 実行一覧を手動で探さずIssueコメントから読む返却処理を提案 |

個別案件では[アメふるPR #109の既存CI復旧監査](https://github.com/miyazaki1016/emergencyalert/blob/6e650705260825c33a9905bbd3802919ba341cc4/docs/audits/PR109_CI_RECOVERY_20261103.md)にも、最新HEADと新しいrunのhead_shaを一致させて確認し、旧成功を流用しない手順がある。この既存知見を再利用し、今回は全担当AI向けの終了時ルールへ整理する。新しいCI収集器・検証器は追加しない。

## 4段階の報告（全担当AIで共通）

| 区分 | 成功・完了を判断する根拠 | 成功を意味しないもの |
| --- | --- | --- |
| 引継ぎ成功 | 対象・制約・既存PR／ブランチ・過去の結論・残課題を把握できた証拠 | 新規変更のテスト合格、案件の完成 |
| 既存成果の再利用成功 | 原本URL、reuse／extend／distinctの理由、継続したPR・ブランチ | コミットを追加しただけ、照合候補の表示だけ |
| 新規変更の検証成功 | 最新HEADと対応した必要なActions・ジョブ・テストの成功、対象SHAと実行URL | 過去SHAの成功、Issueの着手前照合、途中・skip・cancel・失敗 |
| 開発案件の完成 | その案件の受入条件を全て満たす証拠と残課題の解消 | 引継ぎ成功、再利用成功、CI成功、main統合だけ |

## コード変更後の終了前チェック

1. PRの最新HEAD SHAをGitHub APIで取得する。手元の最後のコミット番号だけに依存しない。
2. そのSHAに対応するActions実行を取得し、変更内容とworkflowの起動条件から必要な検証を確認する。実行ID・試行番号・status・conclusion・対象SHA・ジョブの結果・実行URLを記録する。
3. 必要な検証が完了してsuccessの場合だけ「新規変更の検証成功」とする。未実行、実行中、失敗、未確認をそれぞれ明記する。権限不足や取得不能は「未確認」。一覧0件は「対象SHAの実行記録なし」と記録し、合格にしない。skip・cancelled・timed_out・action_requiredをテスト合格にしない。
4. 検証確認後にPRのHEADを再取得し、変わっていれば以前の成功を最新HEADへ流用しない。新しいSHAの確認を未完了として残す。
5. 実機・本番・DB等の確認が未許可なら、確認のために実行せず未確認と記録する。引継ぎが成功していても案件は未完成のままでよい。資料だけの変更で対象外の検証は理由を添える。

Issueの照合はmainのプログラムで走る。**そのrunのhead_shaがmainなら、別ブランチの新規コードをテストした証拠にはならない。** 今回追加するIssue結果コメントも着手前の照合結果の返却であり、最新コードのCIや案件完成を認定する処理ではない。

通常チャットで専用のActions一覧ツールがない場合も、GitHubの汎用取得機能が利用できれば次を読む。コメントに実行IDが記録されている場合は、一覧探索を省略してジョブ・ログを取得できる。

~~~text
GET https://api.github.com/repos/OWNER/REPO/actions/runs?head_sha=最新SHA&per_page=100
GET https://api.github.com/repos/OWNER/REPO/commits/最新SHA/check-runs?per_page=100
GET https://api.github.com/repos/OWNER/REPO/issues/Issue番号/comments?per_page=100
~~~

## 合格待ちは担当AIが継続する（利用者の追加合図は不要）

「進めて」「りょ」等で依頼範囲が確定したら、Issue登録 → 結果取得 → 原本確認 → 判断の一括記録 → 再照合待機 → 合格確認 → 許可された本題を、可能な限り同じ応答内で連続実行する。判断記録だけで応答を終えたり、「続けてよいか」を利用者に聞いたりしない。合格前の案件作業禁止は維持する。

通常チャットでは、まずIssue本文とbotコメントを取得する。未完了なら環境で利用可能な待機機能を使い、目安15〜30秒間隔で再取得する（短時間の連続API呼出しは避ける）。待機中は本文を変更しない。新しい実行が止まるため、結果取得のためだけにIssueを繰り返し編集しない。要確認候補の判断は原本を読んで一括記録する。合格確認後は追加の「りょ」を待たず、元の許可範囲で続ける。

再取得を続けても通常の実行上限を超える、権限・取得エラーがある、応答環境の上限に達した場合だけ、最新状態・Issue URL・分かる実行ID・未着手であることを残して停止する。目安は1回の照合につき10分以内、個々の待機は60秒以内。環境に待機機能がない場合も、その制約を明示する。応答終了後に自動再開できるとは約束しない。

同一Issueの依頼本文・判断記録が一致し、履歴の鮮度・収集状態が既存基準内で、既存の確定合格と実行成功を確認できる場合は、その合格を再利用する。同じ案件の続きへの「りょ」だけではIssue作成・本文編集・再照合をやり直さない。依頼内容・判断・対象が変わった場合やPRの変更パスで新しい候補が出た場合は、既存ルールどおり再照合する。合格確認済みであることは一度簡潔に示し、待機のたびに利用者の操作を求めない。

## 照合完了まで案件作業を開始しない（共通・必須）

引継ぎは「照合段階」と「案件作業段階」の順に行う。照合段階で許されるのは、依頼・制約の確認、既存Issueの登録・更新、照合結果の取得、提示候補の原本確認、reuse／extend／distinctと証拠の記録、再照合の待機・再取得だけ。案件固有の原因調査、仕様検討、設計、コード変更、実験・再測定は、読み取り専用であっても合格確認前に始めない。

通常チャットでもIssueのbotコメントを間隔を空けて再取得し、最新の依頼本文・判断記録に対応する結果を待つ。「起動した」「判断を書いた」「結果待ち」は合格ではない。応答を続けられない場合は「照合待ち・案件未着手」で止め、次の応答では結果取得から再開する。利用者にサイト確認を求めたり、待機の代わりに案件作業を進めたりしない。

着手前に、Issue URL、実行ID／URL、最新依頼・判断との一致、publication_status=confirmed、preflightジョブのsuccess、判定を確認して報告する。要確認候補がある場合はREVIEW_RECORDEDが必要。NO_STRONG_MATCHは照合成功として区別して記録し、候補なしを新規性の保証にしない。未取得・実行中・失敗・INCOMPLETE・REVIEW_REQUIRED・PUBLISHING・SUPERSEDED・本文不一致では着手不可。本文を変更したら旧合格は流用しない。

合格確認後も、元の依頼で許された作業範囲だけを進める。照合成功は、DB変更・通知送信・マージ等の追加許可でも、変更後CI成功や案件完成の証明でもない。これは担当AIの必須運用であり、GitHubからチャット内の行動を物理的に停止する仕組みではない。


新規実装・調査・修正・再測定の前に、担当AIはユーザーの依頼文をそのまま渡して自動照合する。利用者に検索語を考えてもらわない。履歴を見るよう促すだけで作業を開始しない。

## 通常チャットからの引継ぎ（標準経路）

**引継ぎ先は通常チャットを基本とする。WorkやローカルPythonの実行環境を前提にしない。** Pythonを実行できなくても、GitHub連携でIssueの作成・本文更新とActions結果・ログの読取りができれば、既存のGitHub Actionsに実行を任せられる。

1. 最新mainの `AGENTS.md`、この手順、対象の総覧・台帳をGitHub連携で読む。今回の作業と同じIssueがある場合はそのIssueを再利用し、別案件のIssueは流用しない。
2. 今回の依頼文・目的・守る条件・直前の状況を、対象リポジトリのIssueのタイトルと本文へ登録する。**ソラがGitHub連携で登録し、利用者へPythonやPC操作を求めない。** Issue作成・本文編集で `Existing work preflight (read-only)` が自動起動する。
3. 結果返却処理の導入後は、GitHub連携でIssueコメント一覧を取得し、`github-actions[bot]` の `development-preflight-result:v1` コメントを読む。実行ID・URL・照合結果・原本リンク・判断記録を同じ場所で取得できる。今回のIssue本文の依頼内容・判断記録に対応する結果か照合する。Issueのupdated_atはコメントでも変わるため、時刻だけの一致を要求しない。コメントがまだない、依頼内容が変わった、公開処理が失敗した場合は照合未完了として待機・再取得する。旧成功を流用しない。必要ならコメントの実行IDからジョブ・ログを取得する。専用の実行一覧ツールがなくても、汎用GitHub取得で `https://api.github.com/repos/OWNER/REPO/actions/runs?event=issues&per_page=100` が使えるか確認する。
4. `REVIEW_REQUIRED` は原本確認待ち。提示されたコード・数値・検証対象SHA・未統合研究・残課題を読み、各要確認候補の `id`、`decision`（`reuse`／`extend`／`distinct`）、具体的な `reason`、出力に含まれる `evidence` URLを、Issue本文の `history-preflight` ブロックへ記録する。形式は後述のIssue／PR本文の例を使う。
5. **本文の編集後に作成された新しいActions実行**を確認する。古い実行を再実行しただけで最新本文が反映されたとは決めつけない。`REVIEW_RECORDED` なら記録した再利用方針で未解決分のみ進める。`NO_STRONG_MATCH` でもコード・台帳を確認する。`INCOMPLETE`、権限待ち、実行待ち、結果取得不能は照合完了扱いにしない。
6. 後でPRを作る場合は、Issueをリンクし、**PR本文にも**その時点の候補に対する `history-preflight` 判断を記録する。Issueの判断がPRへ自動転記される仕組みはない。PRでは変更パスも照合するため、候補が増えたら追加確認する。

必要なGitHub連携の機能・権限がそのチャットにない場合は、不足する操作を具体的に伝え、実行済みと報告しない。ローカルPythonがないことと、Actions経由でも照合できないことは区別する。既存のマージ・デプロイ・DB・認証・通知送信の許可範囲は引継ぎ後も維持する。Issue登録・本文更新はVercelへのコードpushや本番デプロイではない。自動コメント送信は追加しない。

| 結果／終了コード | 次にすること |

## 再利用判断の記録（利用者の承認は不要）

通常チャットではIssue本文の `history-preflight` ブロックへ記録し、本文編集で再照合する（形式は後述）。CLIを使う場合は、原本を読んだ担当AIが次のJSON配列をローカルファイルへ保存し、同じコマンドに `--decisions /tmp/preflight-decisions.json` を追加して再実行する。`id` と `evidence` は今回の出力からコピーする。3種類の判断のいずれかと、具体的な理由が必要。短い「確認済み」だけでは通らない。

~~~json
[
  {
    "id": "pr-62",
    "decision": "reuse",
    "reason": "47雨域の見逃し実測を再利用し、同じ比較実験は行わず全画素案の未解決条件だけを調べる",
    "evidence": "https://github.com/miyazaki1016/emergencyalert/pull/62"
  }
]
~~~

`reuse`＝既存成果を再利用、`extend`＝既存成果に不足する条件だけを追加、`distinct`＝原本と比較して別案件と判断。自動処理は原本を読んだか・理由が正しいかの意味までは証明できない。担当AIが根拠と理由の責任を持つ。

## Issue／PRでの自動チェック

`Existing work preflight (read-only)` が、Issue作成・編集・再開、PR作成・編集・コミット更新時に依頼内容を自動照合する。PRは変更パスも自動で読む。根拠を確認する記録が足りなければチェックは失敗し、ActionsのSummaryと `existing-work-preflight` 成果物に候補を残す。IssueではActionsの一覧から結果を確認する。Issueへの結果返却処理を導入する場合は、既存出力を専用のbotコメントへ記録する。PRへの自動コメントは追加しない。

PR／Issue本文には次の形式で判断を残す。JSON内容自体は依頼文の照合から除く。依頼文を消して照合を通すことや、根拠を読まずに候補を別案件扱いすることは禁止。

~~~text
<!-- history-preflight
{"decisions":[{"id":"pr-62","decision":"reuse","reason":"47雨域の見逃し実測を再利用し再測定を省略する。全画素案の未解決条件だけを確認する","evidence":"https://github.com/miyazaki1016/emergencyalert/pull/62"}]}
-->
~~~

Checksの `preflight` → Details → Summary、またはActionsの `Existing work preflight (read-only)` → Summaryを開く。自由な作業文を手動照合する場合はActionsのRun workflowで `task` に入力する。PR作成後のチェックは二重確認であり、着手前の照合（通常チャットはIssue経由、実行環境がある場合はCLI）を代替しない。

ベース側の照合プログラムを実行し、PRのコード・Issue本文はデータとして扱う。読取り権限のみ、8分上限。既存の日次更新・検索画面・承認ボードの役割は維持する。ブランチ保護の設定は変更しないため、チェックを無視するマージまで物理的に禁止するものではない。

## 確度と限界

表記揺れ辞書と語句・コードパスの照合であり、任意の依頼文を理解するLLM解析ではない。未知の表現では候補を逃すことがある。そのため候補なしでも原本・台帳・コード検索を継続する。新しい重要結論は従来どおり日本語履歴に追記する。日次更新はVercelビルドや外部AI料金を使わない。

## Issueへの結果返却の設計と安全条件

既存の `preflight.json`／`preflight.md` 成果物を、別の `publish-issue-result` ジョブでIssueの専用botコメントへ返す。照合器や判断方式は再実装しない。結果はREVIEW_REQUIRED／REVIEW_RECORDED／NO_STRONG_MATCH／INCOMPLETEのまま記録し、実行URLとID・試行番号を付ける。原本確認待ちの失敗も結果として読める。公開確認中はPUBLISHING（着手不可）とし、依頼とコメントを再取得して確認できた場合だけ `publication_status=confirmed` にする。本文に判断を書いて再照合すると、同じbotコメントが新しい結果へ更新される。

- 書込み権限はIssueイベント専用の返却ジョブの短期 `GITHUB_TOKEN` の `issues: write` だけに限定する。照合ジョブは引き続き読取り専用。返却ジョブはmainのコードを使い、PRイベントでは起動しない。APIキーや本番認証の変更は不要。
- 依頼本文・history-preflightは書き換えない。起動イベントに `issue_comment` を追加しないため、結果コメントの作成・更新で再照合ループは発生しない。
- 依頼本文・判断記録の指紋が実行時から変わった場合は旧結果を書き込まない。公開と本文編集が競合した場合はSUPERSEDED（更新前・着手不可）にする。新しい実行・試行の結果を古い実行で上書きしない。人のコメントや別用途のbotコメントも上書きしない。
- REVIEW_REQUIRED、INCOMPLETE、SUPERSEDED、PUBLISHING、結果未取得・不一致では着手しない。REVIEW_RECORDEDでも新規変更のCI成功・案件完成を意味しない。NO_STRONG_MATCHでは通常のコード・台帳確認を続ける。

通常チャットからは `fetch_issue_comments` 相当、またはGitHub汎用取得の `GET /repos/OWNER/REPO/issues/番号/comments` を使う。結果からrun_idが分かるので、利用者がサイトへ行って探す必要はない。[終了時の共通ルールと成功事例](WORK_HISTORY_HANDOFF_VALIDATION.md)も参照。

#!/usr/bin/env python3
"""Link branch overlap evidence to existing PRs and explicit index references only."""
import json
import re
from pathlib import Path

def build(report, overlaps, index_text):
    snap = report.get("snapshot")
    if not isinstance(snap, dict) or not isinstance(snap.get("branches"), dict) or not isinstance(snap.get("prs"), dict):
        raise ValueError("Incomplete snapshot")
    if not isinstance(overlaps, dict) or not isinstance(overlaps.get("branches"), dict) or not isinstance(overlaps.get("shared_paths"), dict):
        raise ValueError("Incomplete file evidence")
    rows = re.findall(r"^\|\s*([AM]-\d+)\s*\|([^\n]+)$", index_text, re.M)
    if not rows:
        raise ValueError("Canonical index rows missing")
    cases = []
    for case, fields in rows:
        # Exact branch names only; do not guess from generic titles.
        cases.append((case, fields))
    assignments = []
    for branch, sha in sorted(snap["branches"].items()):
        if branch == report.get("default_branch"):
            continue
        pr_numbers = sorted(
            [int(num) for num, pr in snap["prs"].items()
             if str(num).isdigit() and isinstance(pr, dict) and pr.get("head_ref") == branch])
        explicit = [case for case, fields in cases
                    if branch in re.findall(r"`([^`]+)`", fields)]
        shared = [path for path, names in overlaps["shared_paths"].items()
                  if isinstance(names, list) and branch in names]
        coverage = overlaps["branches"].get(branch, {})
        assignments.append({
            "branch": branch, "head_sha": sha,
            "pr_numbers": pr_numbers,
            "explicit_case_ids": sorted(set(explicit)),
            "shared_changed_paths": shared,
            "file_evidence_complete": bool(isinstance(coverage, dict) and coverage.get("files_complete")),
            "review_required": True
        })
    return assignments

def render(assignments):
    lines = ["# Branch → PR → existing case review handoff", "",
             "This report contains explicit references and changed-path overlap hints only.",
             "A blank case ID means *unmatched*, not missing from main or unfinished.", "",
             "| Branch | PR history | Explicit index case | Shared-file hints | Evidence |",
             "|---|---|---|---|---|"]
    for entry in assignments:
        esc = lambda x: str(x).replace("|", "&#124;").replace("\n", " ")
        lines.append("| " + " | ".join([
            esc(entry["branch"]), ", ".join("#" + str(x) for x in entry["pr_numbers"]) or "—",
            ", ".join(entry["explicit_case_ids"]) or "要確認",
            ", ".join(esc(x) for x in entry["shared_changed_paths"][:5]) or "—",
            "API partial/unknown" if not entry["file_evidence_complete"] else "API-reported",
        ]) + " |")
    lines += ["", "Before changing the ledger/index: inspect actual code diffs, relevant merged/closed PRs and existing case notes.",
              "Do not auto-create a new case from an unmatched branch. Do not infer completion or delete any branch.", ""]
    return "\n".join(lines)

def main():
    root = Path("inventory-output")
    report = json.loads((root / "report.json").read_text(encoding="utf-8"))
    evidence = json.loads((root / "branch-file-evidence.json").read_text(encoding="utf-8"))
    index = Path("docs/DEVELOPMENT_OPERATIONS_INDEX.md").read_text(encoding="utf-8")
    assignments = build(report, evidence, index)
    (root / "branch-case-handoff.json").write_text(
        json.dumps({"assignments": assignments, "auto_applied": False}, ensure_ascii=False, indent=2) + "\n", encoding="utf-8")
    (root / "branch-case-handoff.md").write_text(render(assignments), encoding="utf-8")

if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""Read-only branch-to-main comparisons. Report evidence, never infer feature completion."""
import json
import hashlib
import os
import urllib.parse
import urllib.request
from pathlib import Path

def compare_rows(report, fetch, evidence=None):
    snapshot = report.get("snapshot") or {}
    branches = snapshot.get("branches") or {}
    default = report.get("default_branch")
    if not isinstance(branches, dict) or default not in branches:
        raise ValueError("Incomplete branch snapshot")
    rows = []
    for name, sha in sorted(branches.items()):
        if name == default:
            continue
        if not isinstance(sha, str) or len(sha) != 40:
            rows.append((name, "inconclusive: missing SHA", "", "", ""))
            continue
        path = "/repos/" + urllib.parse.quote(report["repository"], safe="/") + "/compare/" + urllib.parse.quote(default, safe="") + "..." + urllib.parse.quote(name, safe="")
        try:
            data = fetch(path)
            if not isinstance(data, dict):
                raise ValueError("Unexpected API result")
            status = data.get("status", "unknown")
            ahead = data.get("ahead_by", "?")
            behind = data.get("behind_by", "?")
            files = data.get("files", [])
            if not isinstance(files, list):
                raise ValueError("Missing files list")
            # GitHub compare returns a capped file list. Do not claim coverage at or near the cap.
            coverage = "partial/unknown" if len(files) >= 300 or ahead == "?" else "API-reported"
            if evidence is not None:
                evidence[name] = {
                    "head_sha": sha,
                    "status": status,
                    "files_complete": len(files) < 300 and ahead != "?",
                    "paths": sorted({item["filename"] for item in files
                                     if isinstance(item, dict) and isinstance(item.get("filename"), str)}),
                    "patch_sha256": {item["filename"]: hashlib.sha256(item["patch"].encode("utf-8")).hexdigest()
                                     for item in files if isinstance(item, dict)
                                     and isinstance(item.get("filename"), str)
                                     and isinstance(item.get("patch"), str)
                                     and item["patch"]},
                    "patch_absence": [item["filename"] for item in files if isinstance(item, dict)
                                      and isinstance(item.get("filename"), str)
                                      and not isinstance(item.get("patch"), str)]
                }
            sample = ", ".join(str(f.get("filename", "")) for f in files[:8] if isinstance(f, dict))
            rows.append((name, str(status), str(ahead), str(behind), coverage + ": " + sample))
        except (ValueError, KeyError, OSError) as error:
            rows.append((name, "inconclusive: " + type(error).__name__, "", "", ""))
    return rows

def find_shared_paths(evidence):
    """Potential review leads, not a statement of duplicated implementations."""
    if not isinstance(evidence, dict):
        raise ValueError("Missing evidence")
    by_file = {}
    for branch, info in evidence.items():
        if not isinstance(info, dict):
            continue
        for path in info.get("paths", []):
            # Documentation and CI infrastructure overlap frequently; ignore those paths.
            if path.startswith(("docs/", ".github/", "tests/")) or path.endswith((".md", ".lock")):
                continue
            by_file.setdefault(path, []).append(branch)
    return {path: sorted(names) for path, names in sorted(by_file.items()) if len(names) > 1}


def find_equal_patches(evidence):
    """Exact patch equality only. Hashes are evidence, not a duplicate-feature decision."""
    matches = {}
    groups = {}
    for branch, info in sorted(evidence.items()):
        if not isinstance(info, dict):
            continue
        hashes = info.get("patch_sha256", {})
        if not isinstance(hashes, dict):
            continue
        for path, digest in hashes.items():
            if not isinstance(digest, str) or len(digest) != 64:
                continue
            if path.startswith(("docs/", ".github/", "tests/")) or path.endswith((".md", ".lock")):
                continue
            groups.setdefault((path, digest), []).append(branch)
    for (path, digest), branches in sorted(groups.items()):
        if len(branches) >= 2:
            matches.setdefault(path, []).append({"patch_sha256": digest, "branches": sorted(branches)})
    return matches


def render_equal_patches(matches):
    lines = ["# Identical comparison patches (review only)", "",
             "Matching GitHub compare patch text SHA-256 indicates identical API-returned diff hunks",
             "for one file at the time of this snapshot. This is NOT proof of duplicate features,",
             "commits, or merge safety. Missing/truncated patches cannot be assessed.", "",
             "| Changed path | Matching branch heads | Patch SHA-256 |", "|---|---|---|"]
    for path, groups in sorted(matches.items()):
        for group in groups:
            safe_path = path.replace("|", "&#124;").replace("\\n", " ")
            names = ", ".join(branch.replace("|", "&#124;").replace("\\n", " ") for branch in group["branches"])
            lines.append("| " + safe_path + " | " + names + " | " + group["patch_sha256"] + " |")
    if not matches:
        lines.append("| None observed in available patches | — | — |")
    return "\\n".join(lines) + "\\n"


def render_shared_paths(overlaps, evidence):
    lines = ["# Shared changed-file candidates (review only)", "",
             "Multiple branches changing the same path does NOT establish duplicate functionality.",
             "Check actual patches, merged PR history, and the development ledger.", "",
             "| File | Branches | Evidence coverage |", "|---|---|---|"]
    for path, names in overlaps.items():
        coverage = "partial/unknown" if any(
            not evidence[name].get("files_complete", False) for name in names) else "API-reported"
        safe_path = path.replace("|", "&#124;").replace("\n", " ")
        safe_names = ", ".join(name.replace("|", "&#124;").replace("\n", " ") for name in names)
        lines.append(f"| {safe_path} | {safe_names} | {coverage} |")
    if not overlaps:
        lines.extend(["", "No shared changed paths found in the available API evidence; "
                      "this does not prove absence of duplicated work."])
    return "\n".join(lines) + "\n"


def render(rows):
    lines = ["# Branch-to-main evidence (read-only)", "",
             "This is GitHub compare metadata, not proof that a feature is missing, complete, or safe to merge.",
             "Review full diff, closed PRs, and ledger before taking action.", "",
             "| Branch | Compare status | Ahead | Behind | File evidence |",
             "|---|---|---:|---:|---|"]
    for fields in rows:
        escaped = [str(value).replace("|", "&#124;").replace("\n", " ") for value in fields]
        lines.append("| " + " | ".join(escaped) + " |")
    return "\n".join(lines) + "\n"

def main():
    report = json.loads(Path("inventory-output/report.json").read_text(encoding="utf-8"))
    repo = report["repository"]
    token = os.environ["GITHUB_TOKEN"]
    def fetch(path):
        req = urllib.request.Request("https://api.github.com" + path, headers={

"""Prioritize human review of branch evidence without deciding implementation status."""
import json
from pathlib import Path

def prioritize(handoff, evidence):
    items = handoff.get("assignments")
    shared = evidence.get("shared_paths")
    equal = evidence.get("equal_patches")
    if not isinstance(items, list) or not isinstance(shared, dict) or not isinstance(equal, dict):
        raise ValueError("Incomplete handoff or patch evidence")
    result = []
    for row in items:
        if not isinstance(row, dict) or not isinstance(row.get("branch"), str):
            raise ValueError("Malformed handoff entry")
        branch = row["branch"]
        exact_paths = sorted(path for path, groups in equal.items()
                             if isinstance(groups, list) and any(
                                 isinstance(group, dict) and branch in group.get("branches", [])
                                 for group in groups))
        reasons = []
        if exact_paths:
            reasons.append("identical_api_patch_hints")
        if not row.get("file_evidence_complete"):
            reasons.append("file_evidence_incomplete")
        if not row.get("explicit_case_ids"):
            reasons.append("no_explicit_case_reference")
        if not row.get("pr_numbers"):
            reasons.append("no_historical_pr_reference")
        overlap = sorted(path for path, branches in shared.items()
                         if isinstance(branches, list) and branch in branches)
        if overlap:
            reasons.append("shared_file_paths")
        priority = ("P1_review" if exact_paths or not row.get("file_evidence_complete")
                    else "P2_review" if overlap or not row.get("explicit_case_ids") or not row.get("pr_numbers")
                    else "P3_review")
        result.append({
            "branch": branch, "priority": priority, "reasons": reasons,
            "explicit_case_ids": row.get("explicit_case_ids", []),
            "historical_pr_numbers": row.get("pr_numbers", []),
            "equal_patch_paths": exact_paths[:10],
            "shared_file_paths": overlap[:10],
            "next_action": "Review actual main diff, closed/merged PRs, and existing case notes",
            "auto_applied": False
        })
    return sorted(result, key=lambda x: (x["priority"], x["branch"]))

def render(rows):
    lines = ["# Branch inventory human review queue", "",
             "P1/P2/P3 rank *review urgency*, NOT feature completeness, duplicate status, or merge readiness.",
             "An exact API patch match is only a lead. Unknown API coverage is not a no-change result.", "",
             "| Priority | Branch | Existing case | PR history | Evidence hints |",
             "|---|---|---|---|---|"]
    for item in rows:
        safe = lambda value: str(value).replace("|", "&#124;").replace("\n", " ")
        lines.append("| " + " | ".join([
            item["priority"], safe(item["branch"]),
            ", ".join(item["explicit_case_ids"]) or "unmatched",
            ", ".join("#" + str(n) for n in item["historical_pr_numbers"]) or "unmatched",
            ", ".join(item["reasons"]) or "routine review",
        ]) + " |")
    lines += ["", "Do not create or close cases, alter ledger status, merge, or delete based on this queue.", ""]
    return "\n".join(lines)

def main():
    output = Path("inventory-output")
    handoff = json.loads((output / "branch-case-handoff.json").read_text(encoding="utf-8"))
    evidence = json.loads((output / "branch-file-evidence.json").read_text(encoding="utf-8"))
    rows = prioritize(handoff, evidence)
    (output / "branch-review-queue.json").write_text(
        json.dumps({"candidates": rows, "auto_applied": False}, ensure_ascii=False, indent=2) + "\n",
        encoding="utf-8")
    (output / "branch-review-queue.md").write_text(render(rows), encoding="utf-8")

def search(cases,query):
    tokens=[t.lower() for t in re.split(r'\s+',query.strip()) if t]
    if not tokens: return []
    results=[]
    for c in cases.values():
        text=json.dumps(c,ensure_ascii=False).lower()
        hits=sum(t in text for t in tokens)
        if hits == len(tokens):
            priority=hits+3*sum(t in c.get('title','').lower() for t in tokens)+2*sum(t in json.dumps(c.get('curated',{}),ensure_ascii=False).lower() for t in tokens)
            results.append((priority,c['id'],c))
    return [c for _,_,c in sorted(results,key=lambda x:(-x[0],x[1]))]

#!/usr/bin/env python3
"""Read-only GitHub development inventory. No branch/PR/Issue mutations."""
import datetime as dt
import json
import os
import sys
import urllib.error
import urllib.parse
import urllib.request

REPO = os.environ["GITHUB_REPOSITORY"]
TOKEN = os.environ["GITHUB_TOKEN"]
NOW = dt.datetime.now(dt.timezone.utc)
STALE_DAYS = int(os.environ.get("STALE_DAYS", "14"))
API = "https://api.github.com"

def get(path):
    req = urllib.request.Request(API + path, headers={
        "Authorization": "Bearer " + TOKEN,
        "Accept": "application/vnd.github+json",
        "X-GitHub-Api-Version": "2022-11-28",
        "User-Agent": "development-inventory-readonly",
    })
    with urllib.request.urlopen(req, timeout=30) as response:
        return json.load(response)

def pages(path):
    result = []
    page = 1
    while True:
        separator = "&" if "?" in path else "?"
        batch = get(path + separator + "per_page=100&page=" + str(page))
        if not isinstance(batch, list):
            raise RuntimeError("Unexpected API response")
        result.extend(batch)
        if len(batch) < 100:
            return result
        page += 1

def age(timestamp):
    if not timestamp:
        return None
    updated = dt.datetime.fromisoformat(timestamp.replace("Z", "+00:00"))
    return (NOW - updated).days

def main():
    repo = urllib.parse.quote(REPO, safe="/")
    metadata = get("/repos/" + repo)
    default = metadata["default_branch"]
    branches = pages("/repos/" + repo + "/branches")
    all_prs = pages("/repos/" + repo + "/pulls?state=all")
    prs = [p for p in all_prs if p["state"] == "open"]
    issues = [item for item in pages("/repos/" + repo + "/issues?state=open") if "pull_request" not in item]
    pr_heads = {p["head"]["ref"] for p in prs if p["head"]["repo"] and p["head"]["repo"]["full_name"] == REPO}
    historical_heads = {p["head"]["ref"] for p in all_prs if p["head"]["repo"] and p["head"]["repo"]["full_name"] == REPO}
    findings = []
    for branch in branches:
        name = branch["name"]
        if name == default:
            continue
        # No-PR does NOT mean unfinished. Report only as a review candidate.
        if name not in pr_heads:
            findings.append({"type": "branch_without_open_pr", "name": name,
                             "historical_pr_found": name in historical_heads,
                             "url": "https://github.com/" + REPO + "/tree/" + urllib.parse.quote(name, safe="")})
    stale_prs = [{"number": p["number"], "title": p["title"], "days": age(p["updated_at"]),
                  "url": p["html_url"]} for p in prs if age(p["updated_at"]) is not None and age(p["updated_at"]) >= STALE_DAYS]
    stale_issues = [{"number": i["number"], "title": i["title"], "days": age(i["updated_at"]),
                     "url": i["html_url"]} for i in issues if age(i["updated_at"]) is not None and age(i["updated_at"]) >= STALE_DAYS]
    report = {"repository": REPO, "generated_at": NOW.isoformat(), "default_branch": default,
              "branch_count": len(branches), "open_pr_count": len(prs),
              "open_issue_count": len(issues), "historical_pr_count": len(all_prs), "review_candidates": findings,
              "stale_prs": stale_prs, "stale_issues": stale_issues,
              "caveat": "Candidates are NOT proof of unfinished work. Compare main, merged/closed PRs, and canonical ledger before action."}
    # Stable snapshot for comparison across successful scheduled/manual runs.
    report["snapshot"] = {
        "branches": {b["name"]: b.get("commit", {}).get("sha") for b in branches},
        "prs": {str(p["number"]): {"state": ("merged" if p.get("merged_at") else p["state"]),
                                  "head": p["head"].get("sha"), "updated_at": p["updated_at"],
                                  "title": p.get("title", ""), "body": (p.get("body") or "")[:2000],
                                  "head_ref": p["head"].get("ref", "")}
                for p in all_prs},
        "issues": {str(i["number"]): {"state": "open", "updated_at": i["updated_at"]} for i in issues},
    }
    os.makedirs("inventory-output", exist_ok=True)
    with open("inventory-output/report.json", "w", encoding="utf-8") as f:
        json.dump(report, f, ensure_ascii=False, indent=2)
    summary = ["# Development inventory (read-only)", "",
               "Repository: " + REPO, "Generated (UTC): " + NOW.isoformat(), "",
               "| Metric | Count |", "|---|---:|",
               "| Branches including default | " + str(len(branches)) + " |",
               "| Open PRs | " + str(len(prs)) + " |",
               "| Open issues | " + str(len(issues)) + " |",
               "| Branches without open PR (review only) | " + str(len(findings)) + " |",
               "| Stale PRs (>= " + str(STALE_DAYS) + " days) | " + str(len(stale_prs)) + " |",
               "| Stale issues | " + str(len(stale_issues)) + " |", "",
               "**Do not mark branches unfinished or delete them based on this report.**",
               "Consult the project's canonical ledger, closed/merged PRs and main code first.", "",
               "## Stale PRs"]
    summary.extend("- [#" + str(p["number"]) + "](" + p["url"] + ") (" + str(p["days"]) + "d): " + p["title"].replace("\n", " ") for p in stale_prs)
    summary.append("\n## Stale issues")
    summary.extend("- [#" + str(i["number"]) + "](" + i["url"] + ") (" + str(i["days"]) + "d): " + i["title"].replace("\n", " ") for i in stale_issues)
    summary.append("\nBranch candidates are available in report.json artifact.")
    text = "\n".join(summary) + "\n"
    with open("inventory-output/summary.md", "w", encoding="utf-8") as f:
        f.write(text)
    with open(os.environ.get("GITHUB_STEP_SUMMARY", "/dev/null"), "a", encoding="utf-8") as f:
        f.write(text)
    print(text)

if __name__ == "__main__":
    try:
        main()
    except (urllib.error.URLError, KeyError, ValueError, RuntimeError) as error:
        print("Inventory failed: " + str(error), file=sys.stderr)
        sys.exit(1)

"""Generate read-only inventory change candidates from the prior successful artifact."""
import io
import json
import os

import urllib.error
import urllib.request
import urllib.error
import zipfile
from pathlib import Path

API = "https://api.github.com"
REPO = os.environ.get("GITHUB_REPOSITORY", "")
TOKEN = os.environ.get("GITHUB_TOKEN", "")
CURRENT_RUN = str(os.environ.get("GITHUB_RUN_ID", ""))

class SafeRedirect(urllib.request.HTTPRedirectHandler):
    """Do not forward GitHub bearer tokens to external artifact storage."""
    def redirect_request(self, req, fp, code, msg, headers, newurl):
        redirected = super().redirect_request(req, fp, code, msg, headers, newurl)
        if redirected is not None and urllib.parse.urlsplit(newurl).hostname != urllib.parse.urlsplit(req.full_url).hostname:
            redirected.remove_header("Authorization")
            redirected.unredirected_hdrs.pop("Authorization", None)
        return redirected

OPENER = urllib.request.build_opener(SafeRedirect)

def api(path, binary=False):
    req = urllib.request.Request(API + path, headers={
        "Authorization": "Bearer " + TOKEN,
        "Accept": "application/vnd.github+json",
        "X-GitHub-Api-Version": "2022-11-28",
        "User-Agent": "development-inventory-delta-readonly",
    })
    try:
        response = OPENER.open(req, timeout=30)
    except urllib.error.HTTPError as error:
        # Expose the failed endpoint *path*, never signed query parameters or tokens.
        location = urllib.parse.urlsplit(error.url)
        raise RuntimeError("GitHub artifact lookup HTTP " + str(error.code) +
                           " at " + location.hostname + location.path) from error
    with response:
        return response.read() if binary else json.load(response)

def previous_snapshot():
    repo = urllib.parse.quote(REPO, safe="/")
    runs = api("/repos/" + repo + "/actions/workflows/development-inventory.yml/runs?status=success&per_page=30")
    for run in runs.get("workflow_runs", []):
        if str(run["id"]) == CURRENT_RUN or run["event"] not in ("schedule", "workflow_dispatch"):
            continue
        artifacts = api("/repos/" + repo + "/actions/runs/" + str(run["id"]) + "/artifacts?per_page=100")
        for item in artifacts.get("artifacts", []):
            if item["name"] != "development-inventory" or item.get("expired"):
                continue
            archive = api("/repos/" + repo + "/actions/artifacts/" + str(item["id"]) + "/zip", binary=True)
            with zipfile.ZipFile(io.BytesIO(archive)) as z:
                with z.open("report.json") as f:
                    previous = json.load(f)
            if previous.get("repository") == REPO and "snapshot" in previous:
                return previous, run["id"]
    return None, None

def compare(previous, current):
    changes = []
    for group in ("branches", "prs", "issues"):
        before = previous.get("snapshot", {}).get(group, {})
        after = current["snapshot"][group]
        for key in sorted(set(before) | set(after)):
            if key not in before:
                kind = "added"
            elif key not in after:
                kind = "absent_from_snapshot"
            elif before[key] != after[key]:
                kind = "changed"
            else:
                continue
            changes.append({"type": group, "id": key, "change": kind,
                            "before": before.get(key), "after": after.get(key)})
    return changes


def classify_candidates(changes, index_text):
    """Conservative review-only matching; PR files are evidence, never proof."""
    import re
    rows = re.findall(r"^\|\s*([AM]-\d+)\s*\|\s*([^|]+)\|", index_text, re.M)
    suggestions = []
    for change in changes:
        identifier = str(change["id"])
        details = change.get("after") or change.get("before") or {}
        # Branch snapshots contain SHA strings, while PR snapshots contain dicts.
        # Never treat a branch SHA as PR metadata.
        if not isinstance(details, dict):
            details = {}
        metadata = " ".join(str(details.get(k, "")) for k in ("title", "body", "head_ref"))
        filenames = []
        file_status = "not_applicable"
        if change["type"] == "prs" and identifier.isdigit() and REPO:
            try:
                path = "/repos/" + urllib.parse.quote(REPO, safe="/") + "/pulls/" + identifier + "/files?per_page=100"
                files = api(path)
                filenames = [item["filename"] for item in files if "filename" in item]
                file_status = "partial_first_100" if len(files) == 100 else "complete"
            except (RuntimeError, urllib.error.URLError, ValueError, KeyError):
                file_status = "unavailable"
        text = (identifier + " " + metadata + " " + " ".join(filenames)).lower()
        tokens = set(re.findall(r"[a-z0-9]{4,}", text.replace("_", "-")))
        tokens.update(re.findall(r"[\u3040-\u30ff\u4e00-\u9fff]{2,}", text))
        matches = []
        for case_id, title in rows:
            title_tokens = set(re.findall(r"[a-z0-9]{4,}", title.lower()))
            title_tokens.update(re.findall(r"[\u3040-\u30ff\u4e00-\u9fff]{2,}", title))
            if tokens & title_tokens:
                matches.append(case_id)
        # Generic infrastructure PRs are not forced into product work items.
        infrastructure = any(x in text for x in ("development_inventory", "development-inventory", "inventory-triage"))
        if infrastructure:
            matches = []
        suggestions.append({
            "source_type": change["type"], "source_id": identifier,
            "change": change["change"], "candidate_case_ids": matches,
            "classification": ("automation_maintenance" if infrastructure else
                               "possible_existing" if matches else "needs_review"),
            "ledger_action": "review_only", "proposed_status": None,
            "evidence": "PR metadata and changed file names; unverified token hints",
            "file_evidence": {"status": file_status, "paths": filenames[:100]}
        })
    return suggestions

def write_triage(output, result):

    lines = ["# Development inventory change candidates", "",

             result["note"], "",

END = "<!-- INVENTORY_FACTS_END -->"

def render(report):
    prs = report.get("snapshot", {}).get("prs", {})
    lines = ["## GitHub自動取得の事実（確認用）", "",
             "> この欄はPRメタデータの記録であり、開発完了・本番反映の認定ではありません。", "",
             "| PR | タイトル | 状態 | head SHA | 更新日時 |",
             "| --- | --- | --- | --- | --- |"]
    for number, pr in sorted(prs.items(), key=lambda item: int(item[0]) if str(item[0]).isdigit() else -1):
        if not str(number).isdigit() or not isinstance(pr, dict):
            continue
        if str(pr.get("head_ref", "")).startswith("automation/ledger-facts-"):
            continue
        state = str(pr.get("state", "unknown")).replace("|", "/").replace("\n", " ")
        sha = str(pr.get("head", ""))[:40]
        updated = str(pr.get("updated_at", ""))[:35]
        title = " ".join(str(pr.get("title", "")).split()).replace("|", "/")[:120]
        lines.append(f"| #{number} | {title} | {state} | `{sha}` | {updated} |")
    return "\n".join(lines) + "\n"

def update(ledger, report):
    section = START + "\n" + render(report) + END
    if START in ledger or END in ledger:
        if ledger.count(START) != 1 or ledger.count(END) != 1 or ledger.index(START) > ledger.index(END):
            raise ValueError("Invalid managed markers; refuse to change ledger")
        return ledger[:ledger.index(START)] + section + ledger[ledger.index(END) + len(END):]
    return ledger.rstrip() + "\n\n" + section + "\n"

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--report", default="inventory-output/report.json")
    parser.add_argument("--ledger", default="docs/DEVELOPMENT_LEDGER.md")
    parser.add_argument("--output", default="inventory-output/ledger-proposed.md")
    args = parser.parse_args()
    report = json.loads(Path(args.report).read_text(encoding="utf-8"))
    if not isinstance(report.get("snapshot", {}).get("prs"), dict):
        raise ValueError("PR snapshot missing; refuse to propose ledger update")
    proposed = update(Path(args.ledger).read_text(encoding="utf-8"), report)
    target = Path(args.output)
    target.parent.mkdir(parents=True, exist_ok=True)
    target.write_text(proposed, encoding="utf-8")

    main()

def match_cases(state, task, paths=(), exclude=None, limit=8):
    excluded = {exclude} if isinstance(exclude, str) else set(exclude or [])
    cases = [c for c in state['cases'].values() if c['id'] not in excluded]
    query = tokens(task)
    query_concepts = concepts(task)
    if not query and not paths:
        return []
    documents = [(c, *case_text(c)) for c in cases]
    document_tokens = [(c, p, s, tokens(p), tokens(s)) for c, p, s in documents]
    frequency = Counter(t for _, _, _, p, s in document_tokens for t in (p | s))
    weights = {t: math.log(1 + (len(cases)+1)/(frequency[t]+1)) for t in query}
    total = sum(weights.values()) or 1
    results = []
    for c, primary, secondary, pt, st in document_tokens:
        common = query & (pt | st)
        # Primary findings count in full; body and filenames contribute 30%.
        score = 70*sum(weights[t]*(1 if t in pt else .3) for t in common)/total
        matched_concepts = query_concepts & concepts(primary+' '+secondary)
        primary_concepts = query_concepts & concepts(primary)
        score += min(30, 10*len(primary_concepts))
        overlap = sorted(set(paths) & {f['path'] for f in c.get('files', [])})
        if overlap:
            score += 38
        explicit = bool(c.get('number') and re.search(r'(?:pr\s*#?\s*|#)'+str(c['number'])+r'(?![0-9])', normal(task)))
        if explicit:
            score += 80
        # A generic topic alone (e.g. "notification") is not enough to block work.
        specific = matched_concepts - {'比較検証', '性能', '雨の検知', '通知配信', '承認'}
        required = explicit or bool(overlap) or (score >= 24 and len(primary_concepts) >= 2 and bool(specific))
        if score < 13 and not required:
            continue
        links = evidence_links(c, state['repository'])
        results.append({'id':c['id'], 'title':clean(c['title']), 'score':round(score, 2),
                        'review_required':required, 'matched_concepts':sorted(matched_concepts),
                        'matched_paths':overlap, 'matched_terms':sorted(common, key=lambda t:-weights[t])[:12],
                        'summary':clean((c.get('curated') or {}).get('summary') or c.get('purpose') or c['title']),
                        'conclusion':clean((c.get('curated') or {}).get('conclusion') or '結論未確認。根拠のコード・検証資料を読む'),

def coverage_problems(state, now=None, max_age_hours=48):

    issues = []
    try:
        generated = dt.datetime.fromisoformat(state['generated_at'].replace('Z', '+00:00'))
        age = (now-generated).total_seconds()/3600
        if age > max_age_hours or age < -1:
            issues.append('履歴の更新日時が古い、または未来。日次棚卸しを更新して再照合する')
    except (KeyError, TypeError, ValueError):
        issues.append('履歴の更新日時を確認できない')
    cov = state.get('coverage') or {}
    if cov.get('errors') or not isinstance(cov.get('errors'), list):
        issues.append('履歴の収集エラーまたは収集状態不明')
    active = [c for c in state.get('cases', {}).values() if not c.get('archived')]
    prs = sum(c['id'].startswith('pr-') for c in active)
    if not prs or prs != cov.get('prs'):
        issues.append('全PRの収録件数が一致しない、またはPRがない')
    if sum(c['id'].startswith('branch-') for c in active) != cov.get('branches'):
        issues.append('全作業ブランチの収録件数が一致しない')
    if any(c.get('error') or c.get('state') == '取得不能' for c in active):
        issues.append('証拠取得に失敗した案件がある')
    return issues

def git(*args):
    return subprocess.check_output(['git', *args], text=True, stderr=subprocess.DEVNULL, timeout=120)


def load_history(path=None, repo=None, refresh=True):
    if path:
        return json.loads(Path(path).read_text()), None
    if refresh:
        git('fetch', '--quiet', '--no-tags', 'origin', '+refs/heads/development-history:refs/remotes/origin/development-history')
    revision = git('rev-parse', 'origin/development-history').strip()
    state = json.loads(git('show', revision+':docs/work-history/state.json'))
    if repo and state.get('repository') != repo:
        raise ValueError('Repository/history mismatch')
    return state, revision


def event_task(event):
    item = event.get('pull_request') or event.get('issue') or {}
    body = item.get('body') or ''
    ack = ACK_RE.search(body)
    decisions = json.loads(ack.group(1)).get('decisions', []) if ack else []
    # Never rank the acknowledgment's candidate IDs/URLs as part of the task.
    task = item.get('title', '')+'\n'+ACK_RE.sub('', body)
    exclude = 'pr-'+str(item['number']) if event.get('pull_request') else None
    return task.strip(), decisions, exclude


def event_paths(event):
    pr = event.get('pull_request')
    if not pr:
        return []
    base, head = pr['base']['sha'], pr['head']['sha']
    if not all(re.fullmatch(r'[0-9a-f]{40}', sha) for sha in (base, head)):
        raise ValueError('Invalid commit SHA')
    for sha in (base, head):
        try:
            git('cat-file', '-e', sha+'^{commit}')
        except subprocess.CalledProcessError:
            git('fetch', '--quiet', '--no-tags', 'origin', sha)
    return git('diff', '--name-only', '--no-renames', base+'...'+head).splitlines()

    parser.add_argument('--repo', default=os.environ.get('GITHUB_REPOSITORY'))
    parser.add_argument('--output', default='/tmp/development-preflight')
    parser.add_argument('--no-refresh', action='store_true'); parser.add_argument('--max-age-hours', type=int, default=48)
    args = parser.parse_args()
    output = Path(args.output); output.mkdir(parents=True, exist_ok=True)

            event = json.loads(Path(args.event).read_text())
            task, event_decisions, exclude = event_task(event)
            args.paths = event_paths(event)
            decisions = event_decisions
        else:
            task = args.task or ''
        if len(task.strip()) < 8:
            raise ValueError('Task description too short')
        state, revision = load_history(args.history, args.repo, not args.no_refresh)
        if not REPO_RE.fullmatch(state.get('repository', '')):
            raise ValueError('Invalid repository')
        if args.repo and state['repository'] != args.repo:
            raise ValueError('Repository/history mismatch')
        if args.event and event.get('pull_request'):
            branch = event['pull_request']['head'].get('ref')
            exclude = [exclude]+[c['id'] for c in state['cases'].values()
                                 if c['id'].startswith('branch-') and branch and (c.get('head_ref') or c.get('title')) == branch]
        report = inspect(state, task, args.paths, decisions, exclude, max_age_hours=args.max_age_hours, revision=revision)

    (output/'preflight.md').write_text(markdown(report))

"""Read-only searchable history from existing development inventory snapshot."""
import json
import re
from pathlib import Path
from urllib.parse import quote

def cell(value):
    return re.sub(r"\s+", " ", str(value or "")).replace("|", "&#124;").replace("<", "&lt;").replace(">", "&gt;")

def excerpt(body):
    for original in (body or "").splitlines():
        line = original.strip().lstrip("-*> ").strip()
        if line and not line.startswith(("#", "|", "[vc]", "![", "<")) and len(line) >= 12:
            return cell(line[:180] + ("…" if len(line)>180 else ""))
    return "説明抜粋なし。PR差分とコメントを確認"

def render(report):
    snap = report.get("snapshot") or {}
    prs, branches = snap.get("prs"), snap.get("branches")
    repo = report.get("repository")
    if not isinstance(prs, dict) or not isinstance(branches, dict) or not repo:
        raise ValueError("Incomplete inventory; cannot generate trustworthy index")
    lines = ["# 作業内容の履歴索引（自動棚卸し）", "",
             "生成日時 (UTC): " + cell(report.get("generated_at", "不明")), "",
             "この一覧は過去に何を試したかを探すための索引。説明はPR本文の抜粋であり、検証済みの結論ではない。",
             "PR状態は実装完了・本番反映を意味しない。PR差分、Actions、開発台帳を確認する。", "",
             "## 全PRの作業内容", "",
             "| PR | タイトル | 作業内容（PR本文の抜粋） | 状態 | ブランチ |",
             "| --- | --- | --- | --- | --- |"]
    for num,pr in sorted(prs.items(),key=lambda item:int(item[0]) if item[0].isdigit() else -1,reverse=True):
        if not num.isdigit() or not isinstance(pr,dict): continue
        link = "[#" + num + "](https://github.com/" + repo + "/pull/" + num + ")"
        lines.append("| " + " | ".join([link,cell(pr.get("title")),excerpt(pr.get("body")),
                                            cell(pr.get("state", "unknown")),cell(pr.get("head_ref"))]) + " |")
    lines += ["", "## 全作業ブランチ（main以外）", "",
              "ブランチの存在だけで未完了と判断しない。関連PRがないものは作業内容未調査。",

def build(report, inspect_pr=inspect):
    repo = report.get("repository")
    snapshot = report.get("snapshot")

#!/usr/bin/env python3
"""Conservative PR promotion classifier. Never merges, approves, or deploys."""
import argparse
import json
from pathlib import PurePosixPath

HIGH_RISK_PREFIXES = (
    "src/", "app/", "pages/", "api/", "supabase/", "database/",
    "migrations/", "functions/", "lib/", "server/", "public/",
)
HIGH_RISK_EXACT = {
    "package.json", "package-lock.json", "pnpm-lock.yaml",
    "vercel.json", "next.config.js", "next.config.ts",
    ".env", ".env.production",
}
POLICY_PREFIXES = (".github/", "scripts/",)
FACTS_LEDGER = "docs/DEVELOPMENT_LEDGER.md"

def classify(paths, *, draft=False, complete=True):
    """Fail closed: file names are insufficient proof of safe content."""
    paths = list(paths)
    if draft:
        return {"decision": "hold_draft", "reason": "Draft PR; never promote"}
    if not complete or not paths:
        return {"decision": "hold_incomplete", "reason": "Missing/incomplete file evidence"}
    for path in paths:
        if not isinstance(path, str) or not path or path.startswith("/") or "\\" in path:
            return {"decision": "hold_invalid", "reason": "Invalid changed path"}
        if ".." in PurePosixPath(path).parts:
            return {"decision": "hold_invalid", "reason": "Traversal in changed path"}
    if any(p.startswith(HIGH_RISK_PREFIXES) or p in HIGH_RISK_EXACT
           or p.startswith(".env") for p in paths):
        return {"decision": "owner_approval_required", "reason": "Production or app behavior may change"}
    if any(p.startswith(POLICY_PREFIXES) for p in paths):
        return {"decision": "maintainer_review_required", "reason": "Automation or policy changes cannot self-approve"}
    if FACTS_LEDGER in paths:
        return {"decision": "maintainer_review_required", "reason": "Ledger changes require managed-section diff verification"}
    return {"decision": "maintainer_review_required", "reason": "No content-level allow rule has been verified"}

def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--files-json", required=True, help="JSON list of all changed paths")
    parser.add_argument("--draft", action="store_true")
    parser.add_argument("--incomplete", action="store_true")
    args = parser.parse_args()
    with open(args.files_json, encoding="utf-8") as f:
        paths = json.load(f)
    if not isinstance(paths, list):
        raise ValueError("Expected JSON list of paths")
    print(json.dumps(classify(paths, draft=args.draft, complete=not args.incomplete), ensure_ascii=False))

if __name__ == "__main__":
    main()

"""Classify a PR using trusted main-branch policy and GitHub API metadata. Read-only."""
import json

def fetch_json(path):
    req = urllib.request.Request(
        "https://api.github.com" + path,
        headers={
            "Authorization": "Bearer " + os.environ["GITHUB_TOKEN"],
            "Accept": "application/vnd.github+json",
            "X-GitHub-Api-Version": "2022-11-28",
            "User-Agent": "promotion-review-only",
        },
    )
    with urllib.request.urlopen(req, timeout=30) as response:
        return json.load(response)


def inspect(repo, number):
    root = "/repos/" + urllib.parse.quote(repo, safe="/")
    pr = fetch_json(root + "/pulls/" + str(number))
    if pr.get("base", {}).get("ref") != "main":
        return {"decision": "hold_invalid", "reason": "Target branch is not main"}
    paths = []
    complete = True
    for page in range(1, 12):
        batch = fetch_json(root + "/pulls/" + str(number) + "/files?per_page=100&page=" + str(page))
        if not isinstance(batch, list):
            complete = False
            break
        if any(not isinstance(item, dict) or not isinstance(item.get("filename"), str) for item in batch):
            complete = False
            break
        paths.extend(item["filename"] for item in batch)
        if len(batch) < 100:
            break
    else:
        complete = False
    if pr.get("changed_files") != len(paths):
        complete = False
    result = classify(paths, draft=bool(pr.get("draft", True)), complete=complete)
    return {
        **result, "pr": number, "head_sha": pr.get("head", {}).get("sha"),
        "files_seen": len(paths), "files_complete": complete,
        "auto_merged": False, "approval_granted": False,
    }


def main():
    repo = os.environ["GITHUB_REPOSITORY"]
    number = int(os.environ["PR_NUMBER"])

        result = inspect(repo, number)
    except (urllib.error.URLError, ValueError, KeyError, TypeError) as error:

import unittest
from scripts.development_ledger_proposal import START, END, update

class LedgerProposalTests(unittest.TestCase):
    def setUp(self):
        self.report = {"snapshot": {"prs": {"12": {
            "state": "open", "title": "Review-only change", "head": "abc123", "updated_at": "2026-11-01T12:00:00Z"
        }}}}

    def test_idempotent(self):
        once = update("# 台帳\n", self.report)
        self.assertEqual(update(once, self.report), once)
        self.assertIn("#12 | Review-only change | open |", once)

    def test_preserves_human_notes(self):
        ledger = "# 台帳\n\n## 担当者の判断\n完了ではない\n"
        proposed = update(ledger, self.report)
        self.assertIn("## 担当者の判断\n完了ではない", proposed)

    def test_invalid_markers_fail_closed(self):
        with self.assertRaises(ValueError):
            update(START + "\nno end", self.report)
        with self.assertRaises(ValueError):
            update(END + "\n" + START, self.report)

    def test_does_not_infer_completion(self):
        result = update("# 台帳\n", self.report)
        self.assertIn("開発完了・本番反映の認定ではありません", result)
        self.assertEqual(result.count(START), 1)
        self.assertEqual(result.count(END), 1)
