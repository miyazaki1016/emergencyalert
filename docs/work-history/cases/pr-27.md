```text
アプリ再起動後に既存のPush購読状態を復元します。

- Notification permission が granted の場合だけ確認
- Service Worker の既存Push subscriptionを確認
- 購読済みなら「✓ 通知ON」と表示
- 雨判定、5分監視、Push配信ロジックには変更なし
```
