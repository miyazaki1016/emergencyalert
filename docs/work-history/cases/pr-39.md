## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
実地通知で確認した「止みそう→降った」の違和感を改善。

- 3回RAIN確定と RAIN_ENDING が同時なら「いま雨＋もうすぐ止みそう」を1本で通知
- 実際に伝えた内容に合わせて notification event_type を保存
- RAIN_CONFIRMED / RAIN_CONFIRMED_ENDING を導入
- 強雨防災通知も専用イベント種別と DISASTER urgency で履歴化
- 判定速度・3回確認・防災閾値は変更なし
- 総覧に通知文脈ルールを追記
```
