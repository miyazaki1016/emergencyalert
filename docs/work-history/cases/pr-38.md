## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
## 変更
- 30–50 / 50–80 / 80+ mm/h の予測を防災通知レイヤーとして追加
- 現在すでに降雨中でも将来の強雨化を通知
- 同一降雨では同段階を再通知せず、上位段階への悪化のみ追加通知
- 3回連続 NO_RAIN で防災通知段階をリセット
- 警報・注意報とは別の降水強度予測であることを総覧に明記

既存の生活通知、降った/止んだ確定、止みそう通知は維持。
```
