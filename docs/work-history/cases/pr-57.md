## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
After an episode has fully cleared, a single transient RAIN sample must not re-arm the rain-ending notification. RAIN_ENDING is now eligible only when the previously confirmed weather state is RAINING. Existing 3-check rain confirmation, clear confirmation, Push delivery handling, severe-rain alerts, and radar display are unchanged.
```
