## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
## What
- check the current user's existing watch targets before inserting a new one
- treat a location within 50 meters as already registered
- show the existing label instead of creating a duplicate

## Why
The same Shiohama home location was registered twice, which can cause duplicate monitoring and duplicate Push delivery.

## Scope
Registration guard only. Existing data is not deleted or modified.
```
