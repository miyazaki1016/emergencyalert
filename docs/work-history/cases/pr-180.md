+# サキくる / emergencyalert.news — 製品の原点と完成形（恒久方針）
+
+> **製品方針の正本。日々の開発状況と分離して保存する。**
+> 2026-11-09、ユーザーとの対話で再確認。実装状況については必ず `docs/DEVELOPMENT_LEDGER.md`・現在のコード・本番状態で別途検証し、この文書の「最終像」を本番稼働と混同しないこと。
+>
+> **最重要：LIVE JAPAN が将来のサイトのトップページになる。アメふるはサイト全体の名称ではなく、一つのコンテンツ。**
+
+## ブランドと親子関係
+
+- サイト／親サービス：**emergencyalert.news**。
+- 親サービスの呼称候補：**「サキくる／サキクル」**。旧資料に「コンセプト『サキくる／サキクル』」と記録されているが、**正式名称の最終確定は未確認**。勝手に確定扱いしない。
+- **アメふる**：親サービスに含まれる雨関連コンテンツ。MYアメふると全国大雨予報を含む。
+- **LIVE JAPAN**：親サービスの**最終的なトップページのベース**。独立した気象コンテンツと並列の小さな追加機能に格下げしない。
+- 旧Xアカウント「緊急速報まとめ」(@_emergencyalert) は、全国大雨予報と総合防災・生活安全情報配信の歴史的原点。**当時のX上の総合配信と、現在のアメふるの範囲は同義ではない**。
+
+## 1. 最終的な入口：LIVE JAPAN
+
+日本列島を主役にした、日常でも見たくなるインタラクティブなトップ。コンセプトは「日本の今と、少し先の未来。」「暮らしを、少し先回りする。」。
+
+- **平常時**：地図と昼夜・季節の穏やかな表現。太陽位置に基づく日照演出等はすでに試作あり。飾りを気象観測と誤認させない。
+- **変化があるとき**：日本全国の実際の気象・防災情報を地域別に表示。危険情報を季節・演出より優先し、出典・発表時刻・鮮度・予測／実況の別を明示する。
+- 地図から地域・警報を選択して詳細へ移動。大雨であれば全国大雨予報の詳細や**時刻付き雨雲アニメーション**へ接続する構想。
+- 「これまで・いま・このあと」の時間表現は試作済み。ただし**現時点で実時系列データは未接続**。
+- 地震・津波・気象警報などを扱う長期構想。緊急地震速報（秒単位の予測）の独自再配信は既存方針上、対象外。
+- 原型の正本：PR **#61** `feat/live-japan-experience-prototype`、`app/live-japan/page.tsx`、`docs/LIVE_JAPAN_REAL_DATA_INTEGRATION_PLAN.md`。**既存試作を改めて作り直さずに評価・再利用**する。
+
+## 2. アメふる：二つの雨関連コンテンツ
+
+### 2-A. MYアメふる
+- 利用者が地点を登録して、その地点の雨の降り始め・変化を見守り、必要時に通知する。
+- 重点品質は**誤報と見逃しを減らし、予測対象時刻と実際の観測の意味を分けて検証すること**。通知の重複抑制、信頼性、ユーザー体験を優先。
+- MYアメふるの地点別**30mm/h以上の重要通知**と、後述する**全国無登録の大雨一覧**は異なる配信・表示目的。混同しない。
+
+### 2-B. 全国大雨予報 — アメふるの原点／最重要の実現希望
+- **全国のどこかで、今後30分以内に30mm/h以上の雨が予測される地域**を、誰でも地点登録なしで一覧表示する。旧Xでの全国大雨予報投稿のWeb版。
+- 地名、予測時刻、予測強度を確認でき、**選択した地域で気象庁の予測画像を時刻順に再生し、雨雲がどう近づき強まるかが分かる**ことが最も実現したい体験。
+- 歴史的に旧アメふるは**アニメーションGIFを生成**し、X/Twitter側の表示時にMP4へ変換されていた。**旧システムがMP4を生成していたとは書かない**。
+- アニメーションの時刻は実際の公式予測の有効時刻。AIによる架空の雨雲運動や未来フレームの創作をしない。
+- 旧X: https://x.com/_emergencyalert ; 参照投稿: https://x.com/_emergencyalert/status/1663129832178487296/photo/1
+- 旧運用では大雨以外に土砂災害・洪水・ダム放流・暑さ指数・不審者等も投稿していた。これらは**親サービスの歴史**であって、すべてをアメふるに入れる確定仕様ではない。
+
+## 3. 47都道府県データは保護する開発資産
+
+- Supabase Storage `national-rain-n03` に `20260101/01.areas.json` ～ `47.areas.json`、計47ファイル、約440MiB（2026-11-09読取調査）。
+- 全国スキャンで雨域の**30mm/h以上を検出する**処理と、都道府県のポリゴン境界で**該当市区町村を特定する**処理は別。N03データは後者のためのもの。
+- 関連する研究／試作 PR **#59** `feat/national-heavy-rain-preview`：`lib/weather/rain/n03PreparedStorageLoader.ts`、`app/api/rain/national-worker/route.ts`、`.github/workflows/upload-n03-prepared-data.yml`。
+- **本番の全国一覧が現在どの経路から出ているかは未特定**。mainと本番コミットには試作ワーカーが含まれていないという調査だけで、既存一覧の存在を否定しない。実機表示・別サービス・履歴を確かめる。
+- **データを削除・上書きしない。** 容量節約は依存関係・運用実測・代替案を評価してから。現行使用の有無と将来の重要性は別問題。
+
