## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
実地観測で確認した短い雨の途切れを同一エピソードとして表現します。

- confirmed_weather=RAINING のまま clear_streak が1〜2の時は同じ雨
- その状態で生活通知条件を満たしたら「いったん弱まってるけど、また降りそう」
- notification event_type は RAIN_RETURNING
- 3回連続 NO_RAIN 後は従来どおり新しい雨として扱う
- 防災通知・3回確定・v27複合通知は変更なし
```
