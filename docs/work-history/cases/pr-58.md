## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
## Summary
- keep the rain-ending notification latched through dry/forecast wobble
- rearm it only after 3 consecutive RAIN observations confirm a new rain episode
- preserve all rain diagnostics and underlying classification behavior
- ensure a confirmed new episode can still emit a legitimate ending notification
- add focused hysteresis tests

## Scope
Push notification gating only. No rain thresholds, provider logic, diagnostics, location registration, or UI changes.
```
