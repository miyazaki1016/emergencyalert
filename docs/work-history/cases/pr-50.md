## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
Keep 3-consecutive-RAIN confirmation for internal episode/state management, but do not send or persist a standalone RAIN_CONFIRMED notification. If confirmation coincides with RAIN_ENDING, notify only the forward-looking RAIN_ENDING message. Severe, approaching, returning, and ending notifications remain unchanged.
```
