## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
Make the existing rain_confirmed_notified state flag represent internal rain confirmation rather than successful Push delivery. This is required now that standalone RAIN_CONFIRMED Push is intentionally suppressed. The flag still resets after three consecutive NO_RAIN checks. No notification thresholds, severe-rain behavior, or DB schema changes.
```
