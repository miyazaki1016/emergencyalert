## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
Adds a visual OpenStreetMap preview to the coordinate-based monitoring location flow. The existing current-location and address search flows remain unchanged. This lets users visually verify offshore/addressless coordinates before registration, while keeping the implementation small before adding direct map-tap selection.
```
