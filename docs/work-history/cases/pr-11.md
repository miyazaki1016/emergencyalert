## 当時の説明・結論（原文。作者の主張と実測を区別）

```text
The authenticated Edge Function returns HTTP 200 and the iPhone receives the notification, but the client can falsely show failure due to relying on the parsed response payload. Treat a successful Supabase function invocation as success and keep transport errors as failures.
```
