# いいことのさきどり — 暮らしを見守る原点への回帰
2026-11-28 / Issue #329 / 構想・研究段階

## ユーザー方針
本来の基本構想は暮らしを見守る。「いいことのさきどりがいちばん重要」。満月・天体ショー・スターリンクトレインへの関心に着目。「空のさきどり」「季節のさきどり」の方向性を支持。以下の個別機能・コピー・設計はAI提案であり確定仕様ではない。

## 製品思想（提案）
明日の小さな幸せを、今日届ける。楽しみを届ける、暮らしを見守る、いざというとき守る。防災サービスに楽しみを足すのではなく、暮らしを豊かにするサービスに強力な防災機能を備える。平常時は楽しみ、危険時は安全優先、不要な通知はしない。情報ではなく体験のきっかけを届ける。

## 空のさきどり
今夜、空を見上げる理由がある。満月、スーパームーン、流星群、月食・日食、惑星接近、スターリンクトレイン、ISS、ロケット、オーロラ、月面X、虹、彩雲、朝夕焼け、珍しい雲、火球の観測好機。予定・地域・時刻・方角・雲量・明るさを組み合わせ、事前・前日・直前に案内する。日食は安全な観察方法を必須とする。火球や彩雲は発生確約しない。ふたご座流星群ページを年間展開の起点候補にする。

## 季節のさきどり
次の季節に、ひと足早く会いにいこう。春：梅、桜、菜の花、ウグイス、春一番、藤。夏：紫陽花、蛍、ひまわり、花火、セミ。秋：彼岸花、金木犀、紅葉、銀杏、ススキ。冬：初雪、樹氷、霧氷、霜、雪景色、富士山。二十四節気・七十二候と実観測を組み合わせ、桜・紅葉・梅・蛍・初雪の前線を研究する。

## 景色・お出かけ・暮らし
景色：富士山、ダイヤモンド富士、雲海、朝夕焼け、雪景色、夜景、視程。お出かけ：散歩、ドライブ、行楽、花見、ピクニック、海辺、花火、祭り、朝市、無料公開、混雑回避。暮らし：洗濯・布団干し、服装、花粉、黄砂、紫外線、暑さ指数、換気、快適な夜、車の凍結、旬の食材、ごみ収集、断水、電力、交通、道路工事、感染症、潮汐。原点の洗濯物への気遣いを維持する。

## LIVE JAPAN・時間軸
平常時は穏やかな日本地図で各地の楽しみを表示、災害時は安全情報優先。5〜30分先の虹・雨上がり、数時間先の夕焼け・星空・衛星、明日の眺望・洗濯、週末の行楽、1〜2週間先の季節、数か月先の天文予定。毎日開く理由を作る。

## SNS・美咲・既存成果
予測→楽しみ→体験→共有。SNSで事前告知し、将来は観測写真・結果の共有も検討。さきどりが目、美咲が言葉。日常会話で自然に伝え、判定を重複実装しない。既存観測・予報・実況照合・地域判定・地図・スライダー・通知・SNS・イベントページを再利用候補とする。再利用可能性は未検証。

## 品質・評価
公式・信頼できるデータを優先。確定予定、観測予報、条件付き可能性、季節目安を区別。取得費用・規約・再配信・頻度・精度・安全性を確認。欠測は不明とし、過度な期待や通知を避ける。体験を逃さなかったか、快適さ、楽しみ、会話、通知負担も評価する。
