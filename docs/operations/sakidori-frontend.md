# さきどり フロント担当

トップ、MYページ、地図の表示・操作。担当範囲内で表示契約を確認し、データ取得・保存・通知に影響する論点は #256 へ判断を戻す。

- [#256](https://github.com/miyazaki1016/emergencyalert/issues/256) で進行と元指示を確認し、担当PRへ `[SAKIDORI-REQUEST]` と元指示コメントの直接URLを投稿する。
- 所有者の投稿を原本照合し、個別案件の着手前照合が通った依頼だけ処理する。対象HEADとCI、既存の検証証拠を確認する。
- [#287](https://github.com/miyazaki1016/emergencyalert/issues/287) に一件ずつ直接報告する。担当名、元指示と起動コメントのURL、対象、結果、根拠、未決事項を記載し、同じ元指示と担当の報告は一度に限る。
- 自動タスクの範囲は読み取り、設計差分案、外部送信のない隔離合成試験。実装・本番適用は個別の運用手順による。
