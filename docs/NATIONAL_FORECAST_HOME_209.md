# さきどりトップの全国大雨カード

[Issue #209](https://github.com/miyazaki1016/emergencyalert/issues/209) · [着手前照合](https://github.com/miyazaki1016/emergencyalert/actions/runs/43871482625) · [保存基盤 PR #251](https://github.com/miyazaki1016/emergencyalert/pull/251)

公開トップの既存コンポーネントを、250mの30分先までと1kmの35〜60分先のカードに更新。両帯とも降水強度30mm/h以上。カードに自治体、該当予報時刻、最大階級を表示する。雨雲を開くと、最高階級が見つかった周辺のz10タイルに地理院淡色地図を重ね、同じ予報帯の時刻を再生する。1枚のタイルは自治体全域や雨域全体を表さない。カードを開くまで地図を取得しない。

全国走査はPR #243とPR #251の既存判定を再利用。詳細帯を先に保存し、延長帯を同じ基準時刻の追加データとして保存する。欠落・10分期限超過を検出した帯は公開しない。古い保存形式は詳細帯として継続表示し、延長帯の欠落は状態表示とする。35〜60分帯を加えた連続走査の実測は承認前の隔離受入に残す。

## Bluesky用動画をローカルに生成

前提はNode.js、tsx、ffmpegのdrawtext・libx264。入力はフィルタリング前の完全な保存スナップショット。現在の予報以外を混ぜず、画像欠損時は書き出しを失敗させる。Blueskyの投稿本文に自治体名、最大階級、基準時刻を記載できる。

```sh
npx tsx scripts/render-national-rain-mp4.ts snapshot.json 13101 250m output.mp4
```

同じタイルURL生成をブラウザと共有。MP4書き出しは全国スキャンのワークフローから独立。Issue #221 / PR #222のGIFエンコーダーはGIF出力を追加する際の既存資産。今回はMP4を書き出す。既存の投稿ジョブは起動しない。
