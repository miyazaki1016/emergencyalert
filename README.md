# EmergencyAlert 2026

> 暮らしを、少し先回りする。  
> 必要な人に、必要な情報を、必要な時に。  
> 必要でなければ、静かに見守る。


## サービス名称

開発中の正式名称候補は **「サキクル」** に一本化する。

- 名前の意味：暮らしの「この先」に起こる変化を、必要になる前に知らせる。
- 原点の「アメくる？」から、雨だけでなく強雨・猛暑・警報等の生活／防災情報へ広がるサービス思想を表す名称とする。
- ドメインは **emergencyalert.news** を継続使用する。サービス名とドメイン名は一致させる必要はない。
- 「サキクル」は現時点では正式リリース名の最終確定前。商標等の最終確認を行ってから公開名称を確定する。
- 最終確認までは現行UIの「アメくる？」を一斉変更しない。名称確定後にUI・PWA名・メタデータ等をまとめて切り替える。

名称コンセプト：**暮らしを、少し先回りする。**

## 原点

「おかあさん、そろそろ雨降ってくるよ。洗濯物しまったほうがいいよ」

EmergencyAlert は、情報を大量に配信するためのサービスではありません。
正規に発表された情報から、その人の場所と時間に関係する少し先の変化を見つけ、
**今どう動けばいいか分かる形で伝える**ことを目指します。

## 大原則

**EmergencyAlert は天気を予測しない。**

気象庁など正規に発表された予報・観測・防災情報を正本とします。
独自に気象現象・発生時刻・降水量・危険度を予測、補間、改善しません。

AI を使う場合も役割は、公式情報の要約・説明・生活文脈への変換までです。

### データ判定の原則

1. 分からない ≠ 雨なし
2. 欠損を勝手に補間しない
3. 公式情報から言える範囲だけ言う
4. 「雨なし」≠「安全」
5. 通知する価値がなければ静かに見守る

### 通知・事実確定の原則

**予測は早さ優先、結果は確実性優先。**

- 「降りそう」「止みそう」は未来予測なので、公式データから条件を満たした時点で早めに案内する。
- 「降った」「止んだ」は観測結果なので、5分間隔の判定を3回連続で確認してから事実として確定する。
- 「降った」は3回連続 RAIN で確定し、同じ降雨エピソードでは1回だけ通知する。
- 「止んだ」は3回連続 NO_RAIN で確定する。Pushは増やさず、内部状態・画面表示に使う。
- 同じ降雨エピソードでは「止みそう」は1回だけ通知し、3回連続 NO_RAIN でエピソードを終了して次の雨に備える。
- 3回連続 NO_RAIN が揃う前は同じ降雨エピソードとして扱う。その途中で一時的に NO_RAIN となり再び生活通知条件を満たした場合は、新しい雨として「もうすぐ雨」ではなく「いったん弱まってるけど、また降りそう」と案内し、通知履歴は `RAIN_RETURNING` とする。
- 観測事実と未来予測が同時に成立する場合は別々の矛盾して見える通知にせず、1本の自然な文脈にまとめる（例：「いま雨が降ってるよ。でも、もうすぐ止みそう」）。
- 通知履歴の event_type は判定元イベントではなく、実際にユーザーへ伝えた内容と一致させる。降雨確定は `RAIN_CONFIRMED`、降雨確定＋止み予測は `RAIN_CONFIRMED_ENDING` とする。

### 生活通知と防災通知

生活通知（洗濯物など）と防災通知は別レイヤーとして扱う。

- 30〜50 mm/h：気象庁の表現「激しい雨」
- 50〜80 mm/h：「非常に激しい雨」
- 80 mm/h以上：「猛烈な雨」
- 今後の公式降水予測が30 mm/h以上の段階へ到達する場合、現在すでに雨が降っていても防災通知する。
- 同じ降雨エピソードでは同じ段階を繰り返し通知せず、30→50→80のように上位段階へ予測が悪化した場合は追加通知する。
- これらは降水強度の予測通知であり、大雨警報・注意報等の発表を意味しない。警報等は別の公式防災情報レイヤーで扱う。


## Phase 1 — アメくる？2026

最初の完成目標は現在地について、

- 今は降っていない
- このあと生活上知らせる価値のある雨が予報されている
- 雨が弱まりそう／降水のない予報が続きそう

を、気象庁の公式情報に基づいて分かりやすく伝えることです。

初期の生活通知閾値は **5 mm/h 以上が30分以内** を候補とします。
これは気象学的な危険基準ではなく、EmergencyAlert の生活通知用の初期設定値です。

小雨だけなら原則通知しません。降り止みについては、単発のゼロではなく、
連続した有効な公式予報を確認してから案内します。

## Phase 1-A の範囲

DB、Push通知、AI生成はまだ入れません。

```
Browser Geolocation
  -> JmaRainProvider
  -> OfficialRainFrame[]
  -> RainInterpretationEngine
  -> UI / Developer View
```

Developer View では、issue time / valid time / tile / pixel / raw RGBA /
raw state / intensity / source を追跡可能にします。

旧 EmergencyAlert (2023) は思想と試行錯誤を知るための参考資料であり、仕様書ではありません。

**思想は継承する。実装は検証する。**

現行の公式仕様・公式データを確認して実装します。
